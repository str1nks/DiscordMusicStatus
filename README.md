# Discord Music Status

Показывает в Discord, что ты слушаешь в **Яндекс Музыке** (десктопное приложение для Windows): название трека, исполнителя, обложку и полоску прогресса. Работает через Discord Rich Presence.

Программа живёт в фоне без окна, управляется из простого консольного меню и умеет запускаться вместе с Windows.

## Возможности

- **Авто-режим**: статус берётся из Яндекс Музыки через системное медиа-управление Windows. Трек, исполнитель, позиция и длительность подхватываются сами, перемотка и пауза учитываются.
- **Обложки**: ищутся автоматически через публичный поиск iTunes. Если ничего не нашлось, ставится картинка по умолчанию.
- **Пресеты**: можно вручную задать любой «трек» (название, исполнитель, длительность, обложка) и показывать его в статусе, пока ничего не играет или просто так. Пресеты можно добавлять, изменять и удалять.
- **Фоновый процесс**: закрытие терминала статус не убивает. Меню подключается к уже работающему процессу, а если его нет, запускает сам.
- **Автозапуск с Windows**: включается и выключается одним пунктом меню.
- **Отдельный режим «выключено»**: статус убирается, но программа остаётся в фоне.

## Требования

- Windows 10 / 11
- Discord (десктопный клиент, запущенный на этом же компьютере)
- Яндекс Музыка (десктопное приложение)
- Python 3.10+ (только если запускаешь из исходников)

## Быстрый старт из исходников

```bat
git clone https://github.com/<твой-ник>/<репозиторий>.git
cd <репозиторий>

python -m venv venv
venv\Scripts\activate

pip install requests pypresence winrt-runtime winrt-Windows.Media.Control winrt-Windows.Foundation winrt-Windows.Foundation.Collections

python DiscordMusicStatus.py
```

Либо просто запускай `DiscordMusicStatus.bat`: он сам активирует `venv`, если папка есть, и стартует скрипт.

## Сборка в .exe

1. Положи `DiscordMusicStatus.py` и `build_exe.bat` в папку проекта (рядом с `venv`).
2. Запусти `build_exe.bat`.
3. В папке `dist` появятся два файла:
   - `DiscordMusicStatus.exe`: консольное меню;
   - `DiscordMusicStatusBg.exe`: фоновый процесс без окна.
4. Держи оба файла в одной папке и запускай `DiscordMusicStatus.exe`.

Файлов два, потому что фоновый процесс и автозапуск должны работать без чёрного окна, а меню должно быть консольным.

> Если проект лежит в `C:\Program Files\...`, запускай сборку от имени администратора или скопируй папку, например, в `Documents`.

## Использование

При запуске открывается меню:

```
=== Discord Music Status ===

  Фон:         работает, Discord: подключён
  Режим:       авто
  В статусе:   Исполнитель - Трек
  Автозапуск:  выключен

  1. Авто (Яндекс Музыка)
  2. Выбрать пресет
  3. Выключить статус
  4. Пресеты: добавить / изменить / удалить
  5. Автозапуск с Windows: вкл/выкл
  6. Полностью остановить программу
  0. Выйти (программа продолжит работать в фоне)
```

| Пункт | Что делает |
|-------|------------|
| 1 | Статус берётся из Яндекс Музыки автоматически |
| 2 | Показывает выбранный пресет |
| 3 | Убирает статус из Discord |
| 4 | Управление пресетами |
| 5 | Добавляет / убирает программу из автозапуска Windows |
| 6 | Останавливает фоновый процесс и убирает статус |
| 0 | Закрывает меню, фон продолжает работать |

### Пресеты

У пресета есть название, трек, исполнитель, длительность (например `2:38`, `0` значит без полоски прогресса) и необязательная ссылка на обложку. Если обложка не указана, она ищется автоматически.

## Где лежат данные

Всё хранится в `%APPDATA%\DiscordMusicStatus`:

- `config.json`: режим и пресеты;
- `daemon.log`: лог фонового процесса. Если что-то не работает, смотри сюда.

## Настройка

В начале `DiscordMusicStatus.py` есть несколько констант:

| Константа | Назначение |
|-----------|------------|
| `CLIENT_ID` | ID приложения Discord. Можно заменить на свой: создай приложение на [Discord Developer Portal](https://discord.com/developers/applications), его название будет показано как «Слушает …» |
| `APP_KEYWORDS` | По каким частям идентификатора приложения распознаётся плеер |
| `DEFAULT_COVER` | Картинка, если обложку найти не удалось |
| `PORT` | Локальный порт связи меню с фоновым процессом (`127.0.0.1`). Поменяй, если он у тебя занят |

## Как это устроено

В одном файле два режима:

- **демон** (`--daemon`): держит соединение с Discord, раз в несколько секунд читает состояние плеера через Windows Media Control API и обновляет статус;
- **меню**: подключается к демону по локальному сокету и отправляет ему команды.

## Частые проблемы

- **Статус не появляется.** Проверь, что десктопный Discord запущен, а в его настройках включён показ статуса активности. Веб-версия Discord не подходит.
- **«Ничего не играет».** Трек должен именно воспроизводиться в десктопном приложении Яндекс Музыки, на паузе статус не показывается.
- **Не запускается фоновый процесс.** Открой `%APPDATA%\DiscordMusicStatus\daemon.log`.
- **Порт занят.** Измени `PORT` в начале скрипта.
- **Переместил программу, а автозапуск сломался.** Открой меню один раз, путь в автозапуске обновится.
