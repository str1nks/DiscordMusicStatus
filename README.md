# Discord Music Status

**Статус в Discord с тем, что вы слушаете в Яндекс Музыке на Windows**

Название трека, исполнитель, обложка и полоска прогресса в Discord Rich Presence. Программа живёт в фоне без окна, управляется из консольного меню и умеет запускаться вместе с Windows.

## Возможности

### Авто-режим

- **Статус из Яндекс Музыки**: данные берутся через системное медиа-управление Windows, ничего настраивать не нужно.
- **Трек, исполнитель, позиция и длительность** подхватываются сами, перемотка и пауза учитываются.
- **Обложки** ищутся автоматически через публичный поиск iTunes. Если ничего не нашлось, ставится картинка по умолчанию.

### Пресеты

- **Свой «трек» в статусе**: название, исполнитель, длительность и обложка задаются вручную.
- **Показ без плеера**: пресет можно держать в статусе, пока ничего не играет, или просто так.
- **Полное управление**: пресеты можно добавлять, изменять и удалять из меню.

### Фоновая работа

- **Фоновый процесс**: закрытие терминала статус не убивает. Меню подключается к уже работающему процессу, а если его нет, запускает сам.
- **Автозапуск с Windows**: включается и выключается одним пунктом меню.
- **Режим «выключено»**: статус убирается, но программа остаётся в фоне.

## Как это работает

В одном файле два режима:

- **демон** (`--daemon`): держит соединение с Discord, раз в несколько секунд читает состояние плеера через Windows Media Control API и обновляет статус;
- **меню**: подключается к демону по локальному сокету и отправляет ему команды.

```
Меню ──(127.0.0.1:PORT)──▶ Демон ──(Rich Presence)──▶ Discord
                             ▲
                Windows Media Control API
                     (Яндекс Музыка)
```

Меню и демон общаются только внутри вашего компьютера, порт задаётся константой `PORT`.

## Установка

Требуется:

- Windows 10 / 11
- Discord (десктопный клиент, запущенный на этом же компьютере)
- Яндекс Музыка (десктопное приложение)
- Python 3.10+ (только если запускаете из исходников)

### Из исходников

```bat
git clone https://github.com/<твой-ник>/<репозиторий>.git
cd <репозиторий>

python -m venv venv
venv\Scripts\activate

pip install requests pypresence winrt-runtime winrt-Windows.Media.Control winrt-Windows.Foundation winrt-Windows.Foundation.Collections

python DiscordMusicStatus.py
```

Либо просто запускайте `DiscordMusicStatus.bat`: он сам активирует `venv`, если папка есть, и стартует скрипт.

## Сборка .exe

1. Положите `DiscordMusicStatus.py` и `build_exe.bat` в папку проекта (рядом с `venv`).
2. Запустите `build_exe.bat`.
3. В папке `dist` появятся два файла.
4. Держите оба файла в одной папке и запускайте `DiscordMusicStatus.exe`.

| Файл | Зачем |
| --- | --- |
| `DiscordMusicStatus.exe` | консольное меню |
| `DiscordMusicStatusBg.exe` | фоновый процесс без окна |

Файлов два, потому что фоновый процесс и автозапуск должны работать без чёрного окна, а меню должно быть консольным.

> Если проект лежит в `C:\Program Files\...`, запускайте сборку от имени администратора или скопируйте папку, например, в `Documents`.

## Использование

При запуске открывается меню:

```
=== Discord Music Status ===

  Фон:         работает, Discord: подключён
  Режим:       авто
  В статусе:   Исполнитель - Трек
  Автозапуск:  выключен

  1. Авто (Яндекс Музыка)
  2. Выбрать пресет
  3. Выключить статус
  4. Пресеты: добавить / изменить / удалить
  5. Автозапуск с Windows: вкл/выкл
  6. Полностью остановить программу
  0. Выйти (программа продолжит работать в фоне)
```

| Пункт | Что делает |
| --- | --- |
| 1 | Статус берётся из Яндекс Музыки автоматически |
| 2 | Показывает выбранный пресет |
| 3 | Убирает статус из Discord |
| 4 | Управление пресетами |
| 5 | Добавляет / убирает программу из автозапуска Windows |
| 6 | Останавливает фоновый процесс и убирает статус |
| 0 | Закрывает меню, фон продолжает работать |

<details>
<summary>Поля пресета</summary>

| Поле | Описание |
| --- | --- |
| Название | как пресет называется в списке |
| Трек | название трека в статусе |
| Исполнитель | исполнитель в статусе |
| Длительность | например `2:38`; `0` значит без полоски прогресса |
| Обложка | необязательная ссылка на картинку; если не указана, ищется автоматически |

</details>

## Настройка

В начале `DiscordMusicStatus.py` есть несколько констант:

| Константа | Назначение |
| --- | --- |
| `CLIENT_ID` | ID приложения Discord. Можно заменить на свой: создайте приложение на [Discord Developer Portal](https://discord.com/developers/applications), его название будет показано как «Слушает …» |
| `APP_KEYWORDS` | По каким частям идентификатора приложения распознаётся плеер |
| `DEFAULT_COVER` | Картинка, если обложку найти не удалось |
| `PORT` | Локальный порт связи меню с фоновым процессом (`127.0.0.1`). Поменяйте, если он у вас занят |

## Где хранятся данные

Всё лежит в `%APPDATA%\DiscordMusicStatus`:

```
%APPDATA%\DiscordMusicStatus\
├── config.json       режим и пресеты
└── daemon.log        лог фонового процесса
```

Если что-то не работает, смотрите в `daemon.log`.

## Частые проблемы

- **Статус не появляется.** Проверьте, что десктопный Discord запущен, а в его настройках включён показ статуса активности. Веб-версия Discord не подходит.
- **«Ничего не играет».** Трек должен именно воспроизводиться в десктопном приложении Яндекс Музыки, на паузе статус не показывается.
- **Не запускается фоновый процесс.** Откройте `%APPDATA%\DiscordMusicStatus\daemon.log`.
- **Порт занят.** Измените `PORT` в начале скрипта.
- **Переместили программу, а автозапуск сломался.** Откройте меню один раз, путь в автозапуске обновится.
